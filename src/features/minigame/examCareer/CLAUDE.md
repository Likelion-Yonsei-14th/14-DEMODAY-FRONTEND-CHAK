# 수험생 커리어 시뮬레이터

## Patch Note는 꼭 함께 써요

이 폴더의 게임 코드를 바꾸는 PR은 `examCareerPatchNotes.ts`의 `PATCH_NOTES` 맨 위에 새 버전을 하나 추가해야 해요.
게임 시작 화면 맨 아래 "Patch Note"에 그대로 보여요.
테스트 파일(`*.test.ts`, `*.test.tsx`)만 바꾼 PR은 쓰지 않아도 돼요.

CI(`scripts/check-exam-career-patch-notes.mjs`)가 PR마다 확인해요.
이 폴더의 게임 코드가 바뀌었는데 맨 위 버전이 main과 같으면 CI가 실패해요.

### 버전 매기기 (Semantic Versioning)

- PR 하나(머지 하나)에 버전 하나예요.
- 기능을 더하거나 바꾸는 PR은 **중간 자리**를 올리고 마지막 자리는 0으로 돌려요. 예: `1.5.0` → `1.6.0`
- 버그 수정, 문구·확률 조정처럼 고치기만 하는 PR은 **마지막 자리**를 올려요. 예: `1.5.0` → `1.5.1`
- 맨 앞 자리는 게임을 처음부터 다시 만들 정도로 크게 바뀔 때만 올려요.
- 다른 PR이 먼저 머지돼서 버전이 겹치면, main의 최신 버전 다음 번호로 다시 매겨요.

### 문구 쓰기

- 개발자가 아니라 게임을 하는 사람이 읽어요. 파일 이름, 함수 이름, PR 번호는 쓰지 않아요.
- "~했어요", "~해요"처럼 다른 화면과 같은 말투로 한 줄에 하나씩 써요.
- 확률이나 수치를 바꿨다면 이전 값과 바뀐 값을 함께 적어요. 예: "대역전 확률을 5%에서 20%로 올렸어요."
- 날짜는 쓰지 않아요.

```ts
export const PATCH_NOTES: readonly PatchNote[] = [
  {
    version: '1.6.0',
    changes: ['위험한 선택지의 결과가 패널로 번갈아 보이다가 멈춰요.'],
  },
  // ...이전 버전들
]
```
